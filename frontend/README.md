# ChainPilot — Frontend

React + TypeScript + Vite frontend for ChainPilot's supply-chain control tower
and 3D digital twin.

## Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Three.js / React Three Fiber / Drei (digital twin rendering)
- Zustand (client state)

## Structure
See `src/` for module boundaries: `components`, `pages`, `layouts`, `features`,
`digital-twin`, `warehouse`, `logistics`, `control-tower`, `agents`,
`exceptions`, `simulation`, `chat`, `hooks`, `services`, `stores`, `types`,
`utils`, `constants`, `assets`.

## Status
Foundation scaffold only. No application logic has been implemented yet.

## Local development
```bash
npm install
npm run dev
```
