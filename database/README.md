# Database

Alembic migrations and seed data for ChainPilot's PostgreSQL database.

- `migrations/` — Alembic migration scripts (none yet — models not defined)
- `seeds/`      — Seed/fixture data for local development

Domain entities planned for future migrations: Warehouse, WarehouseAisle,
WarehouseBay, Dock, ParkingSlot, Truck, Vehicle, Pallet, InventoryItem,
Shipment, PurchaseOrder, Supplier, CustomerOrder, Exception, Agent,
Recommendation, Action, Simulation, OperationalEvent.
